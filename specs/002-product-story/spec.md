# Spec 002：产品定位、文案与展示图片

状态：首版完成，验证结果见 `tasks.md`

## 目标

PocketIMG 的主要定位为轻量自托管图床，PocketIMG Shot 为与之配合的 Mac 截图工具。Android 保留为可选后端部署方式，减少首页对手机运行图床的强调，不删除能力或暗示停止支持。

## 代码与文档基线

基线提交：`f92e389`。

- README 已称为自托管图床，但 Android 实测结论仍在开头，Mac 功能介绍排在 Android 之后，技术实现细节占据主页面。
- Web 图库顶部与浏览器标题仅显示“图床”，产品名称未统一。
- Mac 已支持截图、方框/箭头/文字、贴图、上传、无音频录屏；仅支持 macOS 14+、Apple Silicon。
- Android 管理 App 是后端部署壳，不是手机访问已有图库所需的上传客户端。
- 仓库有应用图标，但没有可用于产品介绍的图库与 Mac 界面截图。

2. 首屏文案：“轻量自托管图床，让截图更快变成可分享的链接。”

4. 本地构建与手工 Token 配置移入开发文档。保留历史记录，明确其 Android 验收背景。
5. Web 品牌文字与页面标题统一使用 PocketIMG；不修改图库交互、鉴权或部署行为。
6. 第一版使用两张真实 Web 截图及一张 Mac 工作流程图。Mac 实拍暂缺，流程图明确标注“非应用实拍”；不伪造 Mac 应用界面。

## 图片规则

- 用临时本地实例生成演示 Token，通过正常登录与上传 API 填充图库，再用浏览器截图。不修改 DOM 来假装实现额外功能。
- 示例图片使用项目原创的几何排版样张，注明用途；它们是被上传的内容，不是图床本身的编辑功能。
- 截图不得含真实凭证、用户文件或服务器地址；临时数据与服务在拍摄完成后清理。
- 工作流程图采用可维护的 SVG，说明截图、标注、上传、复制链接四步。
- 图片记录来源与复现方式；以后可用真实 Mac 截图替换流程图或补充展示。
