# 前端实现与开发

状态：已实现并通过真机端到端验证
日期：2026-08-12

## 已实现能力

- 使用预配置 Token 换取 `HttpOnly` Session Cookie；Token 只存在于输入框和交换请求中，不做浏览器持久化。
- 页面全局监听粘贴事件，只接收 `image/*`，检测到图片后立即逐张上传并显示进度与结果。
- 单图上传成功后尝试自动复制公开 URL；浏览器拒绝剪贴板写入时保留卡片复制按钮作为降级入口。
- 支持今天、最近 7 天、最近 30 天和全部四个筛选范围，图片按后端返回顺序倒序展示。
- 瀑布流只加载 WebP 缩略图，点击可预览公开全尺寸图。
- 每张卡片提供无文字的复制、永久删除图标；删除前二次确认。
- 鼠标或触控长按约 500 ms 进入多选，支持全选当前结果、批量永久删除和退出多选。
- 提供 Token 更换与退出会话入口；`401` 会清空图库状态并返回 Token 页面。
- 不加载 CDN、在线字体或第三方脚本，运行设备上不需要 Node.js。

## 本地开发

安装固定版本依赖并启动 Vite：

```bash
make frontend-install
cd frontend
npm run dev
```

Vite 用于前端界面开发，不包含后端或网络代理配置。需要验证完整同源链路时，运行 `make build` 将前端嵌入 Go 二进制，再从后端监听地址访问页面。

运行前端测试和生产构建：

```bash
make frontend-test
make frontend-build
```

生产文件输出到 `internal/webui/dist`，随后通过 `go:embed` 编入 Go 二进制。`make build`、`make build-arm64` 和 `make test` 都会先重新生成这组文件。

## 当前边界

- 列表目前一次读取最近 100 张，并在达到上限时显示说明；后端游标接口与前端滚动加载尚未实现。
- 自动复制受浏览器安全策略约束。局域网普通 HTTP 入口可能拒绝异步剪贴板写入，页面会明确提示并保留一键复制按钮；生产 HTTPS 入口需要另行验收。
- 当前按已确认范围不实现频率限制，也不包含 DDNS、TLS、反向代理或远程 URL 转存。

## 真机验收结果

在 PC Firefox 通过设备局域网 HTTP 地址访问服务，已验证：

1. Token 换 Cookie 后进入图库。
2. 粘贴 PNG 后自动上传，手机端生成公开 `.webp` URL 并显示缩略图。
3. 四个时间筛选与卡片复制、删除入口存在。
4. 长按进入多选，从页面确认后永久删除图片，列表随即清空。
5. 测试图片已删除，没有留在目标空间。
